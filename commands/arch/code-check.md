### 3. チェックリスト

#### ① 建築基準法
- [ ] 用途地域の適合性
- [ ] 建ぺい率・容積率
- [ ] 防火・準防火地域の規制
- [ ] 避難経路・避難階段
- [ ] 採光・換気
- [ ] 内装制限（飲食店・宿泊施設の場合は特に注意）
- [ ] バリアフリー（規模による）

#### ② 旅館業法（宿泊施設の場合）
- [ ] 旅館・ホテル営業 / 簡易宿所営業 の区分
- [ ] 和歌山市保健所への届出要件
- [ ] 客室面積基準
- [ ] 浴室・トイレの設置基準

#### ③ 食品衛生法・食品営業（飲食の場合）
- [ ] 飲食店営業許可の要件
- [ ] 厨房設備基準
- [ ] 和歌山市保健所への届出

#### ④ 消防法
- [ ] スプリンクラーの要否
- [ ] 自動火災報知設備
- [ ] 誘導灯
- [ ] 消火器の配置

#### ⑤ その他
- [ ] 景観条例（和歌山市）
- [ ] 屋外広告物条例
- [ ] 長期優良住宅・省エネ基準（リノベーションでの適用）

**重要注意事項**:
- このチェックは参考情報であり、最終的な法規判断は管轄行政庁への確認が必要です。
- 和歌山市は和歌山県建築指導課・和歌山市開発建築部が窓口です。
- 既存不適格建築物のリノベーションは特に注意が必要です。
